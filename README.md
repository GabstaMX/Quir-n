# Quirón — assets de marca y web

Repositorio con las construcciones y assets de Quirón, para que el vibe coding (GHL) y el equipo los tomen a la mano.

## Estructura

```
web/                     Sitio estático
  index.html             Home (usa css/ js/ assets/ relativos)
  clases.html            Cosmovisión / clases
  sistema-diseno.html    Sistema de diseño (autónomo)
  narrativa.html         Narrativa de marca maquetada (autónomo)
  css/                   tokens.css · styles.css · clases.css
  js/                    app.js
  assets/img/            logos usados por la web
  assets/fonts/          DM Sans (web)
  ghl/                   Snippets GHL: header · hero · reservas

encuentra-tu-pack/       Cuestionario "Encuentra tu Pack"
  encuentra-tu-pack.html Build autónomo (referencia)
  SPEC.md                Preguntas + lógica + 3 packs, para construir la página nativa

logos/                   Set completo de logo (PNG): imagotipo · isotipo · logotipo
                         en amarillo · verde · blanco · negro · gris

fonts/                   Familias completas: DM Sans · JetBrains Mono · Spectral (TTF)

brand-css/               CSS listo para pegar en GHL
  00-tokens.css          Variables de marca
  *_lite.css             Cuestionario (#q) · Tienda (#tienda) · Sistema · Clases
                         (sin fuentes embebidas; cargar fuentes por Google Fonts)
```
